# Sentinex Vault — Website

## Files
- `index.html` — complete responsive product page (CSS and JavaScript embedded)
- `sentinex-vault-icon.svg` — matching shield-and-lock icon used as the favicon

## Publish to GitHub Pages
1. Open the `Sentinex-Vault` repository.
2. Upload both files from this folder to the repository root.
3. Replace the existing `index.html` when prompted.
4. Commit the changes and wait for GitHub Pages to redeploy.

The page intentionally marks Sentinex Vault as **In Development** and does not provide an APK download button or assert a confirmed launch date. The feature cards describe the project's intended direction rather than claiming every feature is implemented.
