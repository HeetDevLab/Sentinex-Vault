# Sentinex Vault — Website

## Files
- `index.html` — complete responsive product page (CSS and JavaScript embedded)
- `sentinex-vault-icon.svg` — matching shield-and-lock favicon
- `Sentinex-Vault.apk` — current APK linked from the website download buttons

## Publish to GitHub Pages
1. Open the `Sentinex-Vault` repository.
2. Upload all three files from this folder to the repository root.
3. Replace the existing `index.html` when prompted.
4. Commit the changes and wait for GitHub Pages to redeploy.

The download buttons use the relative path `Sentinex-Vault.apk`, so the APK must be uploaded to the same repository folder as `index.html`. GitHub Pages repository file-size limits may apply; if upload fails, host the APK on a suitable release/download host and update the button URL accordingly. The page explains that this is a direct APK download, not a Play Store listing, and includes installation safety guidance.
