# Sentinex Vault

## Important installation notes

This is a direct APK distribution page, not a Google Play listing. Android may display installation or security prompts for apps installed outside an app store. Users should verify the source, inspect requested permissions, and review system warnings before installing.

## Privacy

Read the [Sentinex Vault Privacy Policy](https://heetdevlab.github.io/Sentinex-Vault/Privacy/). The policy explains file handling, local storage, import/export behaviour, permissions, and relevant limitations. Do not uninstall the app or clear its data without first considering whether that could make locally stored files inaccessible.
